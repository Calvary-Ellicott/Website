# Sermon notes

Two PDFs per week, both named by the Sunday date:

| File                          | What it is                                   | When to add it        |
| ----------------------------- | -------------------------------------------- | --------------------- |
| `sermons/2026-09-13.pdf`       | The handout people follow along with         | Before the service    |
| `sermons/2026-09-13-notes.pdf` | The pastor's full notes for the archive      | After the service     |

Either file can exist on its own. The Watch page shows the newest week's files with download buttons and lists older weeks underneath. It looks back 12 Sundays (`watch.weeksBack` and `watch.weekday` in `data/content.json`).

- Keep the names exact: four-digit year, two-digit month, two-digit day, lowercase, and `-notes` for the full notes.
- Export at a modest size (under about 2 MB) so it loads quickly on phones.
